## Method and limits

**Key points:** All data is synthetic. Only referenced public static assets were read. No provider login, device, shared host, release or update action ran. This is an assessment artifact, not WCAG certification or a test of operational recovery.

**Detail:** Read CLAUDE.md, AGENTS.md, one-right-way.md, UI_STYLE_GUIDE.md, ui-principles.md, frontend-design and the installed ai-copywriter instructions. The repository design system and factual STE take precedence. No separate accessibility or browser skill was available. Existing Playwright used cached Chromium 1223 through an explicit executable path; no browser or dependency was installed.

The isolated app used an archived copy of the assessed source, a fresh test database and the existing DevMode seed. An assessment-only lifespan initialized static status objects but started no polling, scheduler, release checker, notification, backup or RADIUS task. External socket connections and subprocess actions were blocked. Browser requests were limited to loopback; non-read requests were blocked except synthetic login. Fixtures selected first-run password setup, completed setup and a prior declined telemetry prompt. No product source or configuration changed.

Captures used 1440x 900 and 390x 844 with reduced motion. Keyboard probes used the actual menu and settings controls. Bounding boxes and computed colors were read from rendered elements. Contrast used WCAG relative luminance. The app’s local fonts loaded. Status, history, credentials, targets and dates in these images are mock data; none proves live connectivity, authentication, update delivery or backup recovery.

`/setup-wizard` redirects to `/`; it is not a separate wizard page. Add APs & Switches is an inline card, not a dialog. HTTPS and SFTP setup still render. Settings include all requested tabs and subtabs. RADIUS remains shipped; its future removal is separate work. No SSO, device-login, notification Test, certificate, backup Run Now, import, firmware, compliance or push action was submitted.

The website continuation inspected every referenced external script and stylesheet URL before download. Tailwind resolved to 3.4.17; Alpine resolved to 3.17.4. Exact font URLs came from the referenced Google CSS. Twelve declared assets were cached privately; eleven were served during the final browser run. Playwright fulfilled those URLs from the cache. Every other external request and every non-GET request stayed blocked. The local website server exposed only tracked static pages and assets, with no app API.

All four pages rendered with loaded fonts and scrollWidth equal to viewport width at 1440px and390px. The final run had zero page errors and zero unexpected external requests. It scrolled the actual reveal sections and waited for their visible state before full-page capture. Native keyboard probes used actual Alpine controls: Menu Enter opened, Tab reached Features, Space closed, and a local fragment link closed it. Escape left it open. The menu had visible keyboard focus. FAQ Enter opened and Space closed in both sizes. Both controls omitted expanded-state metadata. Each screenshot has a hash and dimensions; full-page height differs from the viewport height by design.

The [static asset manifest](ui-review-2026-10-02/website-static-assets.json) records exact URLs, resolved versions and hashes. The [browser evidence summary](ui-review-2026-10-02/website-evidence.json) records final widths, fonts and keyboard outcomes. The CDNs use mutable URLs; the assessment applies to these captured hashes. No outbound website link, installer, telemetry endpoint or provider was opened. Legal policy content was inspected only for the concrete telemetry mismatch, not legal compliance. Reduced motion was emulated; this review does not certify every animation or WCAG requirement.

Duplicate checks covered open issues, relevant closed issues and every file in all open PRs 271,266 and 153. PR 153 WebSocket tests are superseded by 454; its workflows remain parked. PR 271 touches monitor.html but its auth correction and actual push denial remain separate. The seven follow-ups are sized S/M, safety-path and agent:queued. None is automatically ready. Review exact-line overlap and let the lead select one. Preserve 266’s bench gate and 409’s workflow boundary.

Validation: corrective full offline pytest 1,789 passed, 33 skipped, one existing Starlette/httpx warning,77.40s. Skipped hardware tests provide no bench proof. Documentation links, screenshot dimensions, file hashes and diff whitespace were checked. No UI or code test was added to this documentation-only PR.
