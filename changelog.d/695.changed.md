AP recovery now checks AP-reported CPE return and `eth0` links that were up before reboot.
Bridge data, traffic counters, and link rates no longer gate recovery.
Scheduled updates now follow the derived device queue in serial order.
Each firmware family keeps its maintenance cutoff across scheduler restarts.
Scheduler status reports remaining devices and the current cutoff without predicting phase completion.
Per-device next-window status no longer uses saved wave assignments.
